verify_quotes.py used to compare quotes against the raw bytes of remote PDFs, so every quote from an online PDF showed MISSING (fixed 2026-11-24: pdftotext on remote PDFs; SCANNED_PDF tag when there is no text layer; REPORTED_TIER rows skipped). Before treating MISSING on a PDF source as a bad quote, re-run the verifier — and never lower a row's confidence because of a verifier miss without checking the page yourself.
